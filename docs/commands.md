# Commands

The bot handles these commands:

- `/start` sends the welcome text.
- `/help` sends the command guide.
- `/questions` lists saved questions.
- `/random` sends one saved question and answer.
- `/search word` searches question text.
- `/newfeature text` forwards a bot idea.
- `/newsuggestion text` forwards a program idea.

Telegram group mentions such as `/help@BotName` are parsed as the base command.
